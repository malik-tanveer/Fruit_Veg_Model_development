# Fruit & Vegetable Classification Model

## Introduction

The **Fruit & Vegetable Classification Model** is a Deep Learning project developed to classify images of different fruits and vegetables into their respective categories. The model is built using TensorFlow and Keras and trained on a dataset containing 36 different classes.

This project uses a Convolutional Neural Network (CNN) to learn visual features from images and predict the category of a given fruit or vegetable. The trained model is saved in `.keras` format and will be integrated into a **Streamlit web application**, allowing users to upload an image and view the model's prediction along with its confidence score.

## Technologies Used

* Python
* TensorFlow & Keras
* Pillow (PIL)
* Streamlit
* Numpy
* Jupyter Notebook

## Project Objectives

* Develop and train a CNN-based image classification model.
* Classify images into 36 fruit and vegetable categories.
* Save and reuse the trained model.
* Build an interactive web interface using Streamlit.
* Display predicted classes and confidence scores for uploaded images.
